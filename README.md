# Consultorio Médico "Salud Integral"

Prototipo de un sistema web para centralizar y proteger la información de pacientes, citas e historias clínicas de un consultorio médico pequeño. Proyecto de la actividad de arquitectura de software (análisis de requisitos, UML, patrones de diseño y prototipo en la nube).

> Estado: en construcción. Este README se completa al finalizar el prototipo.

## Estructura del repositorio

```
.
├── backend/     API REST en Python (FastAPI)
├── frontend/    Interfaz web en JavaScript
└── docs/        Documentación y diagramas UML
```

## Tecnologías

- Backend: Python y FastAPI
- Frontend: JavaScript (sin paso de compilación)
- Datos: lista de objetos en memoria, accedida solo a través del patrón Repository
